# Alpha Web Solutions Demo Suite

Upload the contents of this folder to the root of the `alphawebsolutions.github.io` repository.

The home page links to 16 complete demo websites, including the ForgeFit Performance Club gym demo. Each category has a separate URL and its own page title, description, Open Graph details and schema metadata.

The demos work immediately with bundled sample content and ready-made image links. Visitors can click photos to enlarge them. The vehicle-rental demo includes 2-wheeler/4-wheeler filters and a date enquiry; the travel demo includes upcoming departures and seat status. The gym demo includes schedule filters, class reservations, membership selection, a demo member portal, gallery, FAQs and a privacy-policy template.
