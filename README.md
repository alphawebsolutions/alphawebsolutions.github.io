# Alpha Web Solutions Demo Suite

The home page links to 15 complete demo websites with 180 catalogue entries in total—12 balanced items on every demo. Each category has a separate URL and its own page title, description, Open Graph details and schema metadata.

The demos work immediately with bundled sample content and ready-made image links. Visitors can click photos to enlarge them. The vehicle-rental demo includes 2-wheeler/4-wheeler filters and a date enquiry; the travel demo includes upcoming departures and seat status. To make content editable or replace images later, deploy the included Google Apps Script project and paste its `/exec` URL into `assets/js/config.js`.
